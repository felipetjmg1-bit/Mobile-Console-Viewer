# MOBILE CONSOLE VIEWER · fluxo passo a passo

Console JavaScript responsivo para inspeção de logs no navegador.

## 1. ABRIR FERRAMENTA

Carregar a página do console no navegador.

## 2. CAPTURAR REGISTROS

Enviar mensagens de log da aplicação para a interface.

## 3. ACOMPANHAR EVENTOS

Visualizar níveis e timestamps em painel responsivo.

## 4. GERENCIAR HISTÓRICO

Limpar registros ou filtrar a leitura conforme os controles.

## 5. EXPORTAR E DEPURAR

Exportar os registros disponíveis para análise técnica.

## Resultado e limites

Visualizador local de logs. Não é plataforma centralizada de observabilidade ou monitoramento remoto.
